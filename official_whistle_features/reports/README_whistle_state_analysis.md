# Official Whistle Acoustic-State Analysis

## 1. 分析对象

本阶段只分析官方提供的 303 个 whistle 音频片段。它们来自 `data/segments/` 中的官方切片音频，而不是 PAMGuard 自动检测出的全部候选片段。这样做的原因是：官方片段更干净、更适合做第一版声学特征分析和聚类。

本分析不直接识别“开心、悲伤、愤怒、害怕”等具体情绪，而是把 whistle 的频率、能量、持续时间和频谱结构解释为若干 **声学状态候选**，例如低声学活跃、稳定交流、高唤醒候选、强发声候选等。

## 2. 已提取的声学特征

对每个 whistle 音频片段提取了以下特征：

- `duration_sec`：片段持续时间。
- `rms_energy`：均方根能量，反映整体信号强度。
- `peak_amplitude`：峰值振幅，反映最大瞬时强度，但容易受距离、增益和饱和影响。
- `mean_abs_amplitude`：平均绝对振幅。
- `zero_crossing_rate`：过零率，可粗略反映高频成分多少。
- `spectral_centroid_hz`：频谱重心，可理解为声音整体偏高频还是偏低频。
- `spectral_bandwidth_hz`：频谱带宽，反映频率分布范围。
- `spectral_rolloff_85_hz`：85% 频谱能量覆盖到的频率上界。
- `dominant_frequency_hz`：平均频谱中的主导频率。
- `low_freq_est_hz` / `high_freq_est_hz`：基于能量阈值估计的有效频率范围。
- `bandwidth_est_hz`：估计的有效频率跨度。

## 3. 聚类方法

使用标准化后的声学特征进行 PCA 可视化和 KMeans 聚类。当前最终采用 3 类聚类结果。PCA 图显示 303 个 whistle 在二维特征空间中形成了三个相对清晰的区域，说明这些 whistle 在频率、能量和带宽等声学属性上存在可解释的差异。

## 4. 聚类结果总览

| Cluster | 样本数 | 比例 | 推荐中文名 | 状态解释 |
|---:|---:|---:|---|---|
| 0 | 211 | 69.6% | 常规低活跃型 whistle | 低声学活跃 / 常规交流候选 |
| 1 | 71 | 23.4% | 高频宽带高唤醒候选型 | 高唤醒 / 受刺激 / 高频交流候选 |
| 2 | 21 | 6.9% | 高能量强发声候选型 | 强发声 / 近距离或高活动候选 |

## 5. Cluster 0：常规低活跃型 whistle

Cluster 0 包含 211 个样本，是数量最多的一类。它的主要特点是：

- 平均持续时间约 0.681 秒。
- RMS 能量最低，约 0.056。
- 频谱重心最低，约 2195 Hz。
- 主导频率最低，约 682 Hz。
- 有效带宽较窄，约 2134 Hz。

这一类可以视为本数据集中较常规的 whistle 基线类别。它们频率较低、能量较弱、带宽较窄，说明其声学结构相对稳定，不表现出明显的高频化或强能量特征。

因此，Cluster 0 更适合解释为 **低声学活跃或常规交流候选状态**。它不代表“没有情绪”，而是代表从 whistle 声学形态上看，没有明显高唤醒、高能量或强刺激特征。

## 6. Cluster 1：高频宽带高唤醒候选型

Cluster 1 包含 71 个样本。它的主要特点是：

- 平均持续时间约 0.621 秒。
- RMS 能量约 0.130，高于 Cluster 0。
- 频谱重心最高，约 20052 Hz。
- 频谱带宽最高，约 17450 Hz。
- 85% rolloff 频率最高，约 36551 Hz。
- 有效高频上界最高，约 28265 Hz。
- 有效带宽最高，约 28192 Hz。

这一类的最显著特点是 **高频和宽带**。它们包含更丰富的高频成分，频率跨度也更大。这类 whistle 可以作为 **高声学活跃、高唤醒或受刺激状态的候选声学标志**。

需要注意的是，这里不能直接把 Cluster 1 解释为“开心”“紧张”或“害怕”。更严谨的说法是：Cluster 1 在频率结构上表现出更强的高频化和宽带化，因此可能对应更高的 arousal 或更复杂的交流状态。

## 7. Cluster 2：高能量强发声候选型

Cluster 2 只有 21 个样本，是数量最少的一类。它的主要特点是：

- 平均持续时间最短，约 0.499 秒。
- RMS 能量最高，约 0.343。
- 峰值振幅最高，约 0.998，接近满幅。
- 平均绝对振幅最高，约 0.243。
- 过零率最高，约 0.129。
- 主导频率最高，约 8522 Hz。
- 有效频率范围约为 3009–21000 Hz。

这一类最显著的特点是 **能量强**。它可能代表较强的发声片段、距离水听器较近的片段，或者存在接近饱和的强信号。由于振幅特征受录音距离、增益、水声传播和饱和影响较大，因此 Cluster 2 不能简单解释为“情绪最强”。

更合适的解释是：Cluster 2 是 **强发声或高声学活动候选型 whistle**。它可以作为后续寻找高活动片段的重点，但需要配合频谱图或 click 活动背景进一步判断。

## 8. 从 whistle 中能得到的“状态信息”上限

只使用 whistle，当前最多能较合理地得到以下信息：

1. **声学活跃度**：例如低活跃、常规交流、高活跃。
2. **可能的唤醒水平**：高频、宽带、强能量 whistle 可作为高唤醒候选。
3. **交流形态差异**：不同 cluster 可能代表不同 whistle 形态或通信模式。
4. **受刺激/干扰候选**：高频上移或复杂频谱结构可作为受刺激或干扰响应候选。
5. **强发声候选**：高能量 cluster 可提示强发声、近距离或高活动片段。

不能仅凭 whistle 得到以下结论：

- 不能确定海豚具体情绪，例如开心、悲伤、愤怒、恐惧。
- 不能单独判断是否正在觅食，因为觅食更依赖 click train、ICI 和 feeding buzz 分析。
- 不能把振幅直接等同于情绪强度，因为振幅强烈受距离和录音条件影响。

## 9. 最终结论

官方 303 个 whistle 可以被分为三种主要声学状态候选：

- **Cluster 0：常规低活跃型**，占比最高，代表较稳定、低频、低能量的常规 whistle。
- **Cluster 1：高频宽带高唤醒候选型**，具有最高的频谱重心和最宽的频率范围，可作为较高 arousal 或受刺激状态的候选。
- **Cluster 2：高能量强发声候选型**，能量指标显著最高，可能对应强发声、近距离或高活动片段，但需要谨慎解释。

因此，本阶段可以得到的结论是：**whistle 特征确实包含可用于区分海豚声学状态的有效信息，尤其是频率、带宽和能量相关特征；但这些结果应被解释为声学状态候选，而不是确定的具体情绪类别。**
